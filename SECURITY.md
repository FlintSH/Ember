# Security Policy

## Supported Versions

I maintain security updates for the latest stable release of Ember. Rolling builds get fixes as soon as they land on `main`.

| Version | Supported          |
| ------- | ------------------ |
| Latest stable release | :white_check_mark: |
| Rolling | :white_check_mark: |
| Older releases | :x: |

# DO NOT OPEN AI GENERATED SECURITY ADVISORIES IN THIS REPOSITORY

Please make sure every advisory comes from a full **manual** validation of the issue and a demonstrated understanding of it by you, the reporter. Advisories that are not real, or that you haven't verified yourself, waste free, unpaid time.

## Reporting a Vulnerability

Found a security issue in Ember? Thanks for looking out! You can report it in two ways:

1. Click **Report a vulnerability** in the top right corner of this repository.
2. **Email** me@fl1nt.dev with "SECURITY" in the subject.

When reporting, it helps if you can provide:

- What the issue is
- How to reproduce it, including Android and Flare versions
- What could happen if exploited

Issues in Flare itself belong in [Flare's repository](https://github.com/FlintSH/Flare/security).

## What Happens Next

1. I'll confirm I received it when I can
2. I'll investigate and let you know what I find
3. Once fixed, I'll release a patch and credit you (if you want)

See [security and privacy](docs/security.md) for how Ember handles your token, files, and network connections.
